# Agent Harness

**Визначення:** інфраструктура навколо агента (Claude Code), що визначає, що він бачить (база знань через [[MCP]]), що вміє ([[Skill]]) і чого не може ([[Guardrail]]). Не є частиною застосунку — не плутати з [[Recommender]].

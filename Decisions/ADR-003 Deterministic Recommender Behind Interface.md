# ADR-003 Deterministic Recommender Behind Interface

## Контекст
FR-7 вимагає рекомендацій з поясненням; NFR-5 — однаковий результат для однакового стану БД, щоб у ПР № 7 можна було відтворювано порівнювати роботу агента.

## Рішення
- [[Recommender]] — інтерфейс; базова реалізація рахує [[Recommendation Score]] з [[Preference Profile]] за фіксованою формулою.
- Рівні скори впорядковуються за стабільним ключем (id фільму).
- Конкретні ваги формули фіксуються в коді й тестах під час реалізації.

## Альтернативи
- Колаборативна фільтрація — немає інших користувачів.
- LLM-рекомендації — недетерміновані; лишаються опціональним розширенням за тим самим інтерфейсом.

## Наслідки
- Тести можуть перевіряти точний порядок [[Recommendation]].
- Пояснення формується з тих самих складових, що й скор.
